Azure DevOps Work Items User Guide

Welcome! This guide will help you use the Azure DevOps Work Items desktop application. This app is designed to make it easy to manage your work items and tasks in Azure DevOps, all from a simple Windows program.

What Is This App For?

This application helps you:

  • View, add, and organize your Azure DevOps work items and tasks.
  • Track your daily work and time spent on tasks.
  • Start and stop work on tasks, and record your progress.
  • Link tasks to parent work items and manage relationships.
  • Save your daily work and recent tasks for easy access.

Getting Started

What You Need

  • Personal Access Token (PAT):
    The app uses your Azure DevOps PAT, which must be set as an environment variable named AZURE_DEVOPS_PAT on your computer.
  • Organization and Project:
    The app is pre-configured for the "Windowmaker" organization and project. If you need to use a different one, contact your administrator.

App Layout

The main window is divided into several sections:

  1. Header Panel (Top Bar):

    • Work Item ID Field: Enter the ID of a work item you want to fetch.
    • Fetch Button: Loads the work item from Azure DevOps.
    • Task Name Field: Enter a name for a new task.
    • Add Task Button: Adds a new task under the selected work item.
    • Start/Stop Task Button: Starts or stops tracking time for a selected task.
    • Current Task Label: Shows which task (if any) is currently running.

  2. Work Items Grid (Top Section):

    • Shows a list of your main work items.
    • Double-click a row to load its details.

  3. Tasks Grid (Middle Section):

    • Shows tasks related to the selected work item.
    • Right-click for more options (change state, link, remove, etc.).

  4. Today's Work Grid (Bottom Section):

    • Displays tasks you have worked on today and the total hours.

How to Use Each Feature

1. Fetch a Work Item

  • Step 1: Enter the Work Item ID in the top-left field.
  • Step 2: Click the Fetch button.
  • Result: The work item appears in the Work Items grid.

2. Add a New Task

  • Step 1: Select a work item in the Work Items grid.
  • Step 2: Enter a task name in the Task Name field.
  • Step 3: Click Add Task.
  • Result: The new task appears in the Tasks grid, linked to the selected work item.

3. Start or Stop a Task

  • Step 1: Select a task in the Tasks grid (it must be in "Active" state).
  • Step 2: Click Start Task to begin tracking time.
  • Step 3: When finished, click Stop Task.
  • Result: The time spent is recorded and shown in the Today's Work grid.

4. Manage Tasks (Right-Click Menu in Tasks Grid)

  • Change State: Right-click a task, choose State, and select a new state (Proposed, Active, Resolved, Closed).
  • Set Task Type: Right-click, choose Task Type, and pick from the list (e.g., Programming, Code Review).
  • Commit Time: Right-click, choose Commit Time, and select a percentage to log time spent.
  • Start Task: Right-click and select Start Task to begin tracking.
  • Remove Task: Right-click and select Remove Task to delete it from your list.
  • Remove Closed Task: Removes only tasks marked as "Closed".
  • Link/Delink Task: Link a task to a parent work item or remove the link.
  • Set Current Running Task: Mark a task as the one you are currently working on.
  • Fetch Parent: Load the parent work item for the selected task.

5. Manage Work Items (Right-Click Menu in Work Items Grid)

  • Add Task: Right-click a work item, choose Add Task, and select a type to create a new task under it.
  • Add Test Case: Right-click and select Add TEST CASE to create a test case linked to the work item.
  • Remove Work Item: Right-click and select Remove Work Item to delete it from your list.
  • Fetch All Child Tasks: Right-click and select this to load all tasks under the work item.

6. Edit Task Estimates

  • In the Tasks or Work Items grid, double-click the Original Estimate cell to edit the estimated hours for a task.

7. Save and Restore Work

  • The app automatically saves your daily work and recent tasks.
  • You can manually save at any time by pressing Ctrl+S.

8. Clear Lists

  • Clear Tasks: Press Ctrl+Shift+C to clear the Tasks grid (confirmation required).
  • Clear Work Items: Press Ctrl+Shift+W to clear the Work Items grid (confirmation required).

Special Notes

  • Time Tracking: The app tracks your work time and updates Azure DevOps automatically.
  • Lunch/Out-of-Office: The app will stop your running task automatically during lunch (1:00�1:10 PM) or after 8:00 PM.
  • Window Size/Position: The app remembers its size and position between sessions.
  • Pro Features: Some time adjustment features are available only to specific users.

Troubleshooting

  • PAT Not Set: If you see errors about authentication, make sure your AZURE_DEVOPS_PAT environment variable is set.
  • Invalid Work Item ID: If you enter an invalid ID, the app will show a warning.
  • Task Not Active: You can only start tasks that are in the "Active" state.

TaskTracker: Real-Time Employee Activity Monitoring

TaskTracker is a professional desktop application built with the .NET Framework, designed for employers who need to monitor employee productivity and task progress in real time. It provides a seamless and automated way to track user activity, capture screen images, and upload all data to your own secure server, ensuring you always have a clear view of your team's work. The application is lightweight, runs silently in the background, and is built to be both robust and user-friendly for employees.

Key Features

TaskTracker offers a powerful set of features for both employers and employees, ensuring transparency and accountability.

For Employers:

  • Easy Deployment: Install a simple executable (.exe) on each employee's computer.
  • Centralized Configuration: During installation, configure the application to send all data to your own server API endpoint.
  • Customizable Monitoring: Tailor the tracking settings to fit your company's policies:
    • Enable/Disable Screen Capture
    • Allow Automatic Task Pausing
    • Set Screen Capture Frequency
    • Define Inactivity Timeout
  • Real-Time Data Upload: All captured activity logs and screen images are sent to your server in real time.
  • Automated Logging: The application automatically captures key user activities, application usage, and other relevant task data.

For Employees:

  • Simple Login: Employees log in with their credentials to start the tracker.
  • Automatic Tracking: Once logged in, the application works silently in the background, tracking activity and capturing screen images as configured.
  • Smart Inactivity Detection: If the employee is idle for longer than the configured threshold, the task is automatically paused to ensure accurate time tracking.
  • Graceful Shutdown Handling: If the application is closed or terminated unexpectedly, the current task is automatically paused on the server.
  • Power-Aware: The tracker intelligently pauses when the computer goes to sleep or hibernates and reminds to resume when it wakes up.

How Task Tracking Works

The workflow is designed to be simple and automated, requiring minimal interaction from the employee after the initial login.

  1. Login: The employee enters their credentials to log in.
  2. Authentication: The application authenticates the user against the employer's server.
  3. Start Tracking: Upon successful login, the tracker begins monitoring activity and capturing screenshots at the specified interval.
  4. Real-Time Sync: All logs and images are immediately uploaded to the configured API endpoint. If the internet connection is lost, the data is stored locally and uploaded once the connection is restored.
  5. Inactivity Pause: The system monitors for keyboard and mouse activity. If no activity is detected beyond the InactivityThreshold, it sends a request to the server to pause the task.
  6. Logout/Shutdown: When the employee logs out or closes the application, a final request is sent to pause the task, and any pending data is uploaded.

Installation and Configuration Guide

Follow these steps to deploy and configure the TaskTracker application on an employee's machine.

Step 1: Install the Application

TaskTracker.exe or TaskTracker.msi setup will be provided to employer its depending on the requirement.

Step 2: Configure the Server Endpoint

During the installation process, one of the setup steps will prompt the user to input the API Endpoint. The value entered will automatically be saved to the appsettings.json file located in the installation directory.

Step 3: Run the Application

The employee can now run TaskTracker.exe. They will be prompted to log in, and upon success, the tracking will begin automatically.

Usage Guide

  • Login: On the main screen, enter the provided Username and Password and click Login.
  • Monitoring: Once logged in, the application will display a "Running..." status and can be minimized to the system tray, where it will continue to run in the background.
  • Pausing: If the task is paused due to inactivity, the main window will reappear with a "Paused" status. The employee must resume their task from your main task management panel.
  • Logout: To stop tracking, the employee can click the Logout button. This will securely upload any remaining data and end the session.

Technology Stack

TaskTracker is built using a modern and reliable technology stack to ensure high performance and stability.

  • Framework: .NET Framework 4.8
  • User Interface: Windows Forms (WinForms)
  • Core Language: C#
  • Data Handling: System.Text.Json for efficient JSON processing.
